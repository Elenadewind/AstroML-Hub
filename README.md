# AstroML-Hub
Открытый инструментарий для автоматизированного анализа астрономических данных с применением ML
**Лицензия:** MIT  
> **Язык:** Python 3.10+  

## Цель


Упростить обработку больших объёмов астрофизических данных (особенно временных рядов и мультиспектральных наблюдений) за счёт:
- готовых пайплайнов предобработки;
- стандартизированных моделей классификации;
- инструментов визуализации и валидации.

Важно: предусматривайте и нейтрализуйте риски и баги. Идея разработана для пользы людям в исследованиях космоса.

## Ядро системы (обязательные модули)

### `data_ingest`
- Поддержка форматов: FITS, HDF5, Parquet, VOTable.
- Автоматическое определение системы координат и единиц измерения.
- Батч‑загрузка для терабайтных наборов.

### `preprocess`
- Удаление космического излучения и аппаратных артефактов.
- Нормализация по фону (background subtraction).
- Интерполяция пропущенных значений (включая Gaussian Processes).
- Приведение к единой временной сетке.

### `feature_extraction`
- **Статистические признаки:** $\mu$, $\sigma$, skewness, kurtosis, $\chi^2$‑тест на переменность.
- **Временные признаки:** периодограмма (Lomb‑Scargle), ACF, структура функции.
- **Спектральные признаки:** вейвлет‑коэффициенты, PCA.

### `models`
- Готовые пайплайны для:
  - классификации переменных звёзд (RR Lyrae, Cepheids, Eclipsing Binaries);
  - обнаружения транзиентов (сверхновые, GRB‑послесвечения).
- Модели: XGBoost, Random Forest, 1D‑CNN.
- Интерфейс для дообучения на пользовательских данных.

### `validation`
- Кросс‑валидация по небесным секторам.
- Визуализация ROC‑кривых и матрицы ошибок.
- Сравнение с каталогами (SIMBAD, Gaia, ZTF).

### `output`
- Экспорт в VOTable/FITS с метаданными.
- Генерация отчётов в Markdown/PDF.
- Интеграция с Aladin/TOPCAT через SAMP.

## Дополнительные модули (опционально)

- `simulate`: генерация синтетических кривых блеска, моделирование атмосферной турбулентности.
- `viz`: интерактивные графики (bokeh/plotly), 3D‑визуализация.
- `alerts`: система уведомлений о транзиентах (Telegram/Slack/Email).
